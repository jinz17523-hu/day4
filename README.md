# 26 数组（Array）

## 1. 数组概念

数组：

> 相同类型数据元素的集合。

特点：

- 数组只能存储相同类型的数据
- 数组元素在内存中连续存放
- 通过下标访问数组元素


---

## 2. 数组创建与初始化

数组格式：

```
类型 数组名[元素数量]
```


初始化方式：

### 完全初始化

给数组所有元素赋值。


### 不完全初始化

如果初始化元素数量不足：

- 剩余元素默认补充为 0


### 自动计算数组大小

创建数组时可以省略元素数量：

- 编译器会根据初始化内容自动计算数组长度


---

## 3. 数组下标


数组元素通过下标访问。


重点：

- C语言数组下标从 0 开始
- 数组最大下标 = 数组长度 - 1


例如：

```
10个元素的数组

有效下标：

0 ~ 9
```


---

## 4. 数组元素修改


数组中的元素可以直接进行赋值修改。


例如：

修改某个位置的数据：

```
数组名[下标]
```


---

## 5. 数组遍历


数组通常配合循环使用。


常见方式：

- for循环遍历数组
- 通过下标依次访问每个元素


注意：

循环范围：

```
0 <= 下标 < 数组长度
```


---

## 6. 数组输入


使用 scanf 给数组赋值时：


注意：

- 数组名本身代表数组首地址
- 数组元素属于普通变量，需要使用地址符


区别：

```
数组名 → 不需要 &
数组元素 → 需要 &
```


---

## 7. 数组内存特点


数组的重要特点：

> 数组元素在内存中连续存放。


随着数组下标增加：

- 地址逐渐增加
- 元素之间距离固定


这也是后续学习指针的重要基础。


---

## 8. sizeof计算数组大小


sizeof可以计算：

- 数组占用内存大小
- 单个元素大小


计算数组元素数量：

```
数组总大小 ÷ 单个元素大小
```


这是C语言中计算数组长度的常用方法。


---

# 9. 二维数组


二维数组：

> 数组里面存放数组。


类似于：

- 表格
- 矩阵


格式：

```
数组名[行][列]
```


例如：

```
3行5列
```


---

## 10. 二维数组初始化


二维数组同样支持：

- 完全初始化
- 不完全初始化


不完全初始化：

- 未赋值位置默认补0


初始化时：

可以使用多个花括号区分不同的行。


---

## 11. 二维数组注意事项


创建二维数组时：

可以省略：

```
行数
```


但是不能省略：

```
列数
```


原因：

编译器需要知道每一行包含多少元素。
